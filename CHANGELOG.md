# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.2.0] - 2026-07-13

### Added

- Added a `SKILL.md` skill definition and a Claude Code agent definition.
- The installer now registers the skill with Claude Code, Codex, and Gemini when present, and registers the agent with Claude Code.
- Added `--dry-run`, `--home`, and `--help` installer flags.

## [2.1.0] - 2026-07-13

### Changed

- Sanitized framework examples and replaced personal references with fictional placeholder personas.
- Removed the internal status table from the Age of AI workshop framework.

## [1.0.0]

### Added

- Initial public release.
